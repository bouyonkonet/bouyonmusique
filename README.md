# BouyonMusique.com

Guide francophone et anglophone de la musique bouyon : histoire, artistes, styles, producteurs, playlists.
The French and English guide to bouyon music, published by Bouyon Shattaz.

- French site: https://bouyonmusique.com/
- English mirror: https://bouyonmusique.com/en/
- Built as static HTML, hosted on GitHub Pages with the custom domain bouyonmusique.com.
